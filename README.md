# WPC Data Mapping

Mind map แบบคลิกได้ของระบบข้อมูลสินค้าอะไหล่ WPC (ไฟล์ข้อมูลดิบ → ฐานข้อมูลสินค้า → ช่องทางจำหน่าย)

- `index.html`: หน้า Mind Map และดีไซน์
- `data.js`: เนื้อหาด้านในของแต่ละหัวข้อ (แก้ไฟล์นี้เมื่อเพิ่มข้อมูล)
- `firebase.json`: ตั้งค่า Firebase Hosting

Deploy: `firebase deploy --only hosting`
